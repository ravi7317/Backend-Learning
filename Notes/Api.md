## what is api
1. Do alag alag application ko communication krwane ke liye jo set of rules and protocall use krte hai use api khte hai
2. ye do application 1 apka backend server dusra frontend 

## Types of apis
1. Rest (Representational State of transfer Protocol)
2. SOAP (Simple Object Access Protocol)
3. RPC (Remote Procedure Call)
4. GraphQl Apis
5. WebSocket Apis

## what is Restapi
1. Rest api(Representational State API) here we use HTTP protocol and some HTTP method  GET POST PUT PATCH DELETE

## Use Of Http Method
1. GET => jab hame data server se lena ho ya fetch krna ho
2. POST => jab server pr data send krna ho
3. PATCH => Jab data server pr already hai aur us data ko update krna hai 
4. DELETE => server pr data hai aur use delete krna hai
